# 2D Platform Game (Python)

A 2D platformer built in Python using Pygame, focused on implementing core game mechanics such as movement, collision detection and basic physics.

## Overview

This project was developed to explore fundamental game development concepts, including:

- Game loop structure  
- Event handling  
- Collision systems  
- Player movement and interaction  

It serves as a practical application of programming logic and system design.

---

## Tech Stack

- Python  
- Pygame  

---

## Features

- Player movement (left/right/jump)  
- Collision detection  
- Basic gravity system  
- Interactive environment
